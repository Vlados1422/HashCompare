# 🔐 HashCompare — Сравнение хэшей файлов

![React](https://img.shields.io/badge/React-18-61dafb.svg)
![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6.svg)
![Vite](https://img.shields.io/badge/Vite-6-646cff.svg)

**HashCompare** — современное веб-приложение для вычисления и сравнения хэшей файлов. Поддерживает алгоритмы MD5, SHA-1, SHA-256 и SHA-512. Все вычисления выполняются локально в браузере — ваши файлы не отправляются на сервер.

![HashCompare Screenshot](screenshot.png)

## ✨ Возможности

- 📁 **Вычисление хэшей файлов** — загрузите файлы и получите все основные хэши
- ✏️ **Ручное сравнение** — введите хэши вручную и сравните их
- 🔄 **Автоматическое сравнение** — загрузите несколько файлов для сравнения
- 📋 **Копирование в буфер** — быстрый доступ к хэшам
- 📱 **Адаптивный дизайн** — работает на всех устройствах
- 🔒 **Безопасность** — все вычисления локальны, файлы не загружаются на сервер
- 🎨 **Современный интерфейс** — темная тема с градиентами

## 🧮 Поддерживаемые алгоритмы

| Алгоритм | Длина | Назначение |
|----------|-------|------------|
| **MD5** | 128 бит (32 символа) | Быстрая проверка целостности |
| **SHA-1** | 160 бит (40 символов) | Устаревший, но еще используется |
| **SHA-256** | 256 бит (64 символа) | **Рекомендуется** для большинства задач |
| **SHA-512** | 512 бит (128 символов) | Максимальная надежность |

## 📖 Использование

### Вычисление хэшей файлов

1. Перейдите на вкладку **«Хэши файлов»**
2. Перетащите файлы в область загрузки или нажмите **«Выбрать файлы»**
3. Дождитесь вычисления всех хэшей (MD5, SHA-1, SHA-256, SHA-512)
4. Скопируйте нужный хэш кнопкой копирования рядом с ним
5. Сравните с хэшем, предоставленным источником файла
6. Если загружено 2+ файла — автоматическое сравнение появится внизу

### Ручное сравнение хэшей

1. Перейдите на вкладку **«Ручное сравнение»**
2. Вставьте хэши в поля ввода (можно добавить больше полей)
3. Нажмите кнопку **«Сравнить»**
4. Результат покажет, совпадают ли хэши

## 💡 Практические примеры

### 🔽 Проверка скачанного файла

Многие сайты предоставляют хэш файла рядом со ссылкой для скачивания. После загрузки файла вычислите его хэш и сравните с указанным.

**Пример:** На сайте указано `SHA-256: a1b2c3...` — загрузите скачанный файл и сравните.

### 📦 Проверка установщика приложения

Перед установкой программы из интернета проверьте её хэш. Если хэш отличается от официального — файл мог быть изменён.

Официальные хэши обычно публикуются на сайте разработчика или в репозитории.

### 🔄 Сравнение двух версий файла

Загрузите два файла одновременно. Приложение покажет, идентичны ли они. Это полезно для проверки, была ли обновлена конфигурация или документ.

### 🛡️ Обнаружение вредоносных изменений

Если хэш известного безопасного файла изменился — это может означать, что файл был заражён вирусом или модифицирован злоумышленником.

> ⚠️ **Важно:** Всегда используйте SHA-256 или SHA-512 для критических проверок.

## ⚠️ Важные замечания

- **MD5 устарел** — не используйте его для проверки безопасности, только для быстрой проверки целостности
- **SHA-256 — золотой стандарт** — рекомендуется для большинства задач проверки подлинности
- **Регистр не важен** — при ручном сравнении регистр букв (a/A) не влияет на результат
- **Все вычисления локальны** — файлы не отправляются на сервер, всё обрабатывается в вашем браузере
- **Размер файлов** — очень большие файлы (>1 ГБ) могут потребовать больше времени для обработки

## ❓ Частые вопросы

**Почему хэши одного файла на разных сайтах отличаются?**
Скорее всего, используются разные алгоритмы (MD5 vs SHA-256). Убедитесь, что сравниваете хэши одного алгоритма.

**Можно ли по хэшу восстановить файл?**
Нет. Хэш — это односторонняя функция. Из хэша невозможно получить исходный файл.

**Что делать, если хэши не совпадают?**
Попробуйте скачать файл заново. Если хэши всё ещё не совпадают — файл мог быть повреждён при передаче или модифицирован.

**Безопасно ли загружать файлы в это приложение?**
Да! Все вычисления происходят локально в вашем браузере. Файлы никуда не отправляются.
